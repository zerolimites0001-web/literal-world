# Literal World 🌍

Um mundo 3D procedural gerado diretamente no navegador! Explore biomas incríveis, montanhas gigantes, florestas e vales, tudo renderizado de forma fluida.

## 🛠️ Tecnologias Utilizadas
- **Three.js** para renderização 3D.
- **JavaScript** para a lógica do jogo e geração procedural (seed).
- **Vite** / HTML5 puro para rodar direto no navegador.

## 🎮 Como Jogar
- Use os controles na tela (joystick virtual) para se movimentar e olhar ao redor.
- Explore o terreno e encontre novos biomas!
- *(Em breve)* Mecânicas de construção e interação com blocos.

## 🚀 Como Executar Localmente
1. Clone este repositório.
2. Abra o arquivo `index.html` no seu navegador, ou rode um servidor local (ex: `npx serve`).
